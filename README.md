# AI Travel Itinerary Planner 

A full-stack AI-powered travel itinerary generator built as a capstone project for the NASSCOM FutureSkills Prime Skill Wallet requirement.

## Tech Stack
* **Frontend:** React.js, Vite, Axios, Supabase JS Client
* **Backend:** FastAPI, Python, Google Gemini AI (`google-generativeai`)
* **Database:** Supabase PostgreSQL (JSONB storage for flexible itinerary rendering)
